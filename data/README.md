# Datasets

Datasets are not stored in git. Download them into this folder.

## METU / Ozgenel Concrete Crack Images (about 40,000 images)
1. Download "Concrete Crack Images for Classification" from Mendeley Data
   (DOI 10.17632/5y9wdsg2zt) -- "Download All".
2. Unzip (the zip contains a .rar; extract it with 7-Zip or WinRAR) so you have:
   ```
   data/metu/Positive/   (20,000 cracked images)
   data/metu/Negative/   (20,000 clean images)
   ```

## CrackForest (CFD, 118 images with pixel-level masks)
